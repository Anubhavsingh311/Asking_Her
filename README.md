# Asking Her 💌

A playful "Will You Be My Valentine?" web app. The "No" button gets progressively harder to click, eventually dodging the cursor entirely.

## Demo

[Live Site](https://anubhavsingh311.github.io/Asking_Her/)

## Features

- Multi-stage rejection flow with escalating, humorous prompts
- "No" button that flees from the cursor on the final stage
- Tenor GIF embeds for visual flair
- Responsive, lightweight, no build step required

## Tech Stack

HTML, CSS, vanilla JavaScript

## Usage

Clone the repo and open `index.html` in a browser, or fork it and swap in your own GIFs, copy, and styling to personalize it.

```bash
git clone https://github.com/Anubhavsingh311/Asking_Her.git
```
